# 💰 Personal Finance App

A simple personal finance application built with **.NET MAUI** that helps users manage their daily expenses and visualize their investment portfolio allocation.

## 📱 Features

### Expense Tracker

- Add and manage expenses
- Categorize spending
- View total expenses
- Monitor spending habits

### Portfolio Asset Allocation

- Track investment assets
- View allocation across different asset classes
- Understand portfolio distribution at a glance
- Monitor investment balance

## 🛠️ Tech Stack

- .NET MAUI
- C#
- XAML
- MVVM
